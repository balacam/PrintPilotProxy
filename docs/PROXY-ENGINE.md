# Proxy Engine

PrintPilotProxy uses the **Unobtanium Web Proxy** engine (version 0.1.5, MIT License).

## Why Unobtanium?
We evaluated several engines:
- Titanium
- YARP
- Caddy
- Squid
- FiddlerCore
- PassThroughProxy

Unobtanium provides the right balance of a native .NET API, robust connection handling, and lightweight footprint.
