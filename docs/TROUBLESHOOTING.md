# Troubleshooting

## Common Issues

### Port in use
**Symptom**: Proxy service fails to start, logs indicate port binding error.
**Solution**: Change the configured port in `config.json` or stop the conflicting service.

### Firewall Blocking
**Symptom**: Proxy is running but clients cannot connect.
**Solution**: Ensure Windows Firewall has an inbound rule allowing the configured port.

### Client Can't Connect
**Symptom**: Connection timeout from the client.
**Solution**: Verify the client IP is in the Allowed Clients list. Check the proxy logs for rejection notices.

## Diagnostics
Logs are generated by Serilog and saved to disk. Check the log files for errors.
