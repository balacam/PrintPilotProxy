# Installation Guide

## Requirements
- OS: Windows 10/11 or Windows Server 2019+
- Runtime: .NET 8 Runtime

## Download
Get the latest release from the [GitHub Releases](https://github.com/PrintPilotProxy/releases) page.

## First Run
1. Run the installer or extract the zip archive.
2. Launch the `PrintPilotProxy.UI.exe` as Administrator to configure the service.
3. Add your client IPs to the Allowed Clients list.
4. Start the service from the UI.
